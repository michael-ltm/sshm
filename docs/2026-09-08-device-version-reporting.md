# 设备安装版本与代理版本显示修复

客户端发布：`0.8.0-cloud-preview.30`。最终 Cloudflare Worker：`e9a6c1e1-3f9e-4cf2-93f1-f4be98b32176`。

## 原因与实机证据

设备页原先把 `/v1/heartbeat` 的 `version` 直接当作安装版本。该字段实际来自运行进程的编译常量，替换磁盘文件后旧进程继续发送旧版本，而且多个进程能轮流覆盖它。

修复前实测：MacBook Air 磁盘 `.29`，Mac mini 磁盘 `.22`，GrokBot 磁盘 `.25`；三者心跳均 `.18`。Mac mini 的 `.cargo/bin` 和 `.local/bin` 是指向 `/opt/homebrew/bin/sshm` 的软链接，并非三份安装。`tmp-ai-compute` 离线，上次进程上报 `.25`，不能据此判断当前磁盘文件。

## 修改

- 独立的 `/v1/client-version` 安装观察记录；认证使用本设备登录态，无需保险库口令。不会使离线设备变成在线，也不改变运行版本。浏览器身份不能冒充本机安装探测。
- Go 客户端从启动时记住的安装路径读取真实文件版本，先校验 Go 主程序身份，再不经 shell 启动 `version` 子命令；时间和输出大小都有边界。进程内旧版本常量不充当磁盘版本；探测失败保留历史记录。
- 安装脚本、更新后的 integration refresh（兼容旧更新器）、设备列表、首页版本检查与新版周期心跳刷新安装信息。正常本地模式不要求登录；网络失败不阻止已完成的安装。
- 活跃中继连接单独报告 `runtime_version`。网页分开展示安装版本、代理状态、待重启及观察时间。旧代理不支持精确版本声明时明确写“版本未上报”，不伪造实时版本。
- 历史安装观察超过 90 秒不再标为刚确认的绿色最新版；显示上次确认时间。离线旧进程版本是历史记录，不能当作当前安装文件。
- 手动刷新也重新检查签名发布清单。下发更新比较真实磁盘版本，避免已安装但未重启时重复下载。
- 异步任务路由返回后重新读取账号和校验凭据，防止并发旧心跳保存旧账号快照、覆盖刚收到的安装记录。
