# 本地优先官网精简

官网的主流程改为安装客户端和本地连接。云同步仍可选，浏览器加密和远程功能的授权边界保持不变。

- 首页移除模拟云设备列表，主按钮直接打开安装说明，不要求登录或解锁。
- 安装说明先展示本地启动；旧连接迁移、AI 集成与云同步分别折叠。移除安装流程中的常驻网页终端代理步骤，后台同步使用 `sshm service install`。
- 设备列表移除重复的保险库解锁列；“加入保险库”保留在行菜单。心跳明确标记为云端状态，避免误认为本地 SSH 不可用。
- 删除服务器页面重复的任务下发按钮。设备任务与下发记录放入“高级功能”，网页终端说明也折叠保留。
- 明确网页保险库锁定与本地凭据独立，删除把代理重启解锁要求套用到所有连接的说明。

验证：类型检查、20 项 Node 测试、18 项 Vitest 测试和 8 组真实 Chromium 回归通过；包括本地安装不弹登录/解锁、高级任务、真实合成保险库解密、私钥逐字节导出、退出及 390px 布局。桌面与手机截图已人工核对。代码审查发现的 PowerShell 5.1 不支持 `&&` 问题已修正为分行命令。

部署 Worker 版本：`efeb5f24-a321-4d10-bd67-77220b383907`。客户端仍为已签名的 `0.8.0-cloud-preview.35`，本次没有重建或替换客户端下载文件。网页入口、脚本、安装器和发布清单的上线核对记录保存在忽略目录 `dist/site-simplification-20260928/live-verification.json`；截图位于同目录。
